# Modo de prueba aislado de FrameXTV

Esta versión inicia directamente en el embed de FrameXTV para el ID TMDB `969681`:

`https://framextv.xyz/embed/969681?autoplay=1&muted=0`

No se abre una ficha del catálogo, no se actualizan listas IPTV y no se elige una fuente IPTV antes de entrar al reproductor. El embed se renderiza directamente en WebView. Usa Atrás para salir del reproductor; al salir se navega a la pantalla principal.

Este es un cambio temporal de prueba para evaluar la apariencia y el comportamiento del reproductor antes de extender la integración al catálogo completo.
